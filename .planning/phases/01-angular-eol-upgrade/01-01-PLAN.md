<objective>
Establish a provable pre-upgrade baseline for `game-planner-ui`, then execute the first Angular
major-version hop (13 -> 14) end-to-end as this phase's tracer slice: `ng update` -> build -> test ->
boot smoke -> one commit. Every subsequent hop repeats this exact loop, so proving it once here
de-risks the remaining eight.

Purpose: Angular 13.3.0 has been unpatched since ~April 2023 (`.planning/codebase/CONCERNS.md`).
This phase moves the SPA to a supported major. This plan proves the upgrade loop works before
committing to it nine times.
Output: A verified Angular 13 baseline record plus the app running on Angular 14, committed.
</objective>

<target_version_resolution>
## TARGET VERSION: Angular 22 — read this before starting

CONTEXT.md **D-01** says "upgrade to whatever Angular version is under active LTS support at
execution time" and gives the rationale "maximizes the security-patch runway".

RESEARCH.md (Open Question 1) flags that this phrase blends two distinct phases in Angular's own
release model, and resolves it as follows:

| Version | Angular's support phase | Support window |
|---------|-------------------------|----------------|
| 20      | LTS (critical fixes only) | ends ~late 2026 |
| 21      | LTS (critical fixes only) | ends ~mid 2027 |
| **22**  | **Active** (latest stable, 22.1.4) | Active through ~2027-06, then LTS through ~2028-06 |

**Resolution: the target is Angular 22.** It has the longest total remaining support window, which is
exactly what D-01's stated rationale asks for. A literal reading of the word "LTS" would land on v21.

**If the developer intended v21, say so now** — stopping one hop earlier is a trivial change to this
plan set (drop plan `01-05`'s hop task). Once the v22 hop lands, reverting is a git revert plus a
lockfile regeneration.

Per D-01's own instruction to "re-confirm the exact current LTS number at execution time", the
executor of Task 2 re-checks `angular.dev/reference/releases` before starting. If Angular 23 has
shipped since 2026-08-28, STOP and report rather than silently extending the hop chain — this plan
set is scoped to nine hops ending at 22.
</target_version_resolution>
