<objective>
Lock in the Phase 2 external-credential contract for `IgdbService` and `SteamService` with fully
offline tests (D-01), and fix the real defect research found: the Steam API key is written to
Information-level logs by HttpClientFactory's own request logging on every Steam call.

Purpose: Phase 2 redacted the service catch blocks, but the leak path is configuration, not
service code — `System.Net.Http.HttpClient.*` loggers print the full request URL including
`?key=`. A test that bypasses the real pipeline cannot see this, which is how it survived. This
plan proves the leak with a failing test through the real pipeline, closes it with one config
key, then expands to the stub-based transport and failure-surfacing contract.

Output: one `appsettings.json` key, `SteamServiceContractTests.cs`, `IgdbServiceContractTests.cs`.
</objective>
