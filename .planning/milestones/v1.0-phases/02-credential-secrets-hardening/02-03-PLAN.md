<objective>
Make the eight Manager/Service-tier `catch (Exception)` blocks that wrap external API calls stop being silent: raise severity where the failure means real data loss, count the items that were skipped, and hand those counts to the `WorkerStatus` mechanism plan 02-02 created.

Purpose: REL-03. Today a sync can drop hundreds of games' images and still report a clean "Completed" run — the failure exists only as a Debug/Warning line nobody reads. This closes the gap the ROADMAP words as "surfaced rather than silently dropped".
Output: eight instrumented catch sites, five changed manager/service signatures, and four workers reporting partial failures.
</objective>
