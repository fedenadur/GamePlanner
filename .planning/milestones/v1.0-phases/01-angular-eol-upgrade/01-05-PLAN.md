<objective>
Complete the upgrade: the final Angular hop (21 -> 22) including the TypeScript 5.9 -> 6.0 major
jump, then bring the independently-versioned supporting dependencies — the Jasmine/Karma family,
`@types/jasmine`, `@types/node` and RxJS — up to versions compatible with Angular 22.

Purpose: This plan is where DEP-01 and DEP-02 are actually satisfied. The v22 hop is the heaviest of
the nine because TypeScript crosses a major boundary and can surface previously-silent type errors in
application code that no Angular change caused. The supporting-dependency bump is separate because
`ng update` does not manage those packages — only `karma` itself is gated by an Angular peer range.
Output: `game-planner-ui` on Angular 22 with a compatible, booting test harness.

**Target for the phase is Angular 22** — see `01-01-PLAN.md` &gt; `<target_version_resolution>` for why
v22 rather than v21, and how to override if v21 was intended. This is the last chance to change that
decision cheaply.
</objective>
